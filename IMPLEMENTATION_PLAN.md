## W07 — Register numerical methods and uncertainty semantics

- [ ] Implement unit-aware quantities with Pint and reviewed domain vocabularies, NumPy/SciPy methods, Polars/DuckDB/Arrow bounded queries and Pandera-style dataset contracts. Keep pure scientific calculations separate from storage, networking and UI. Registry entries declare method ID/version, inputs, dimensions, assumptions, failure rules, tolerance, uncertainty, outputs and provenance.
- [ ] Implement oxygen partial pressure `pO2 = xO2 × P_absolute`, percent/fraction conversion and optional ideal-gas molar density under explicit temperature/ideal-gas assumptions. Known-answer cases include 21% at 14.7 psia → 3.087 psia and 30% at 10.2 psia → 3.06 psia; similar partial pressures do not establish equal flammability. Preserve fraction and pressure separately; a relative concentration increase is not a fire-probability increase.
- [ ] Implement calibrated flame-front slope fitting with defensible intervals and ignition-transient handling; droplet `K = -d(D²)/dt` fits with explicit diameter, support, regime segmentation and residuals; event timing with distinct failed ignition, sustained burning, visible extinction, cool-flame cessation, disruption, intentional termination and observation-end states. Preserve censoring and competing risks rather than forcing binary outcomes.
- [ ] Implement detector timing only with defined generation/start event, synchronized clocks, transport path, instrument response, threshold and alarm endpoint. Sensitivity/specificity/ROC/false-positive rates require labeled positives and negatives. Smoke observations or dust sessions alone cannot supply them.
- [ ] Register Reynolds, Peclet, Damköhler, Grashof and Richardson definitions only with required characteristic length, velocity, properties, temperature, gravity and timescale. Register heat-release/oxygen-consumption calculations only with source-specific mass balance, flow, calibration and transient corrections. Missing inputs produce a structured refusal/need-for-data result.
- [ ] Implement uncertainty propagation `J Σ Jᵀ` when linearization is justified, and Monte Carlo propagation with justified distributions/covariance, convergence checks and recorded seed when necessary. Keep measurement uncertainty, run variability, parameter uncertainty, numerical error, discrepancy and extrapolation distinct. Unreported uncertainty stays unreported; analyst sensitivity ranges cannot impersonate measured error bars.
- [ ] Support normalized/display units without altering stored precision or refitting models; handle non-finite values, invalid denominators, missing values, significant digits and censored observations explicitly. Store calculation inputs, selected intervals/exclusions, code/environment versions and output artifacts.

**Evidence:** independent known-answer tests, dimensional/property checks and source-specific golden cases with justified tolerances. A successful Python execution or unit conversion is not scientific validation of the underlying assumptions.

## W09 — Fit two measured trace types and gate any run-level prediction

- [ ] Expose two descriptive fits using the registered W07 implementations. For calibrated flame-front position against time, save the identified front, spatial scale, clock, direction and chosen interval, with the ignition transient treated explicitly. For measured droplet diameter squared against time, verify the diameter definition, support and burning regime before reporting the negative slope as a burning-rate constant. Show the original points, fitted line, physical units, residuals, exclusions and assumptions. Both fits describe only the selected measured interval and regime.
- [ ] Keep acquisition conditions, calibration, source anchors, source hashes, time window, independent run/sample counts and fit version with the result. Report uncertainty or intervals only when the measurement and error model support them, accounting for within-run dependence. State what each interval means. Missing calibration, unresolved units/regime, insufficient points or an invalid fit returns the specific limitation.
- [ ] Run a single trusted, fixed-method fitting child on the existing CPU worker, independent of the interactive sandbox and OpenAI. Start with one fit at a time, one CPU thread including numerical-library threads, 30 seconds elapsed and 512 MiB total per fitting child including runtime, buffers and any descendants. Measure real imports, inputs, memory and time before release. If a limit is reached, report it and let the researcher explicitly select and freeze a smaller interval or cohort, with selection and exclusions visible. Never silently sample, expand the budget or publish a partial fit as complete.
- [ ] Optionally register **one predefined small linear regression** for one specified continuous endpoint and one prespecified predictor using comparable, independent experimental runs, with one analyzed outcome per independent unit. Define the protocol, exclusions, baseline and target use before evaluating it. Group data across shared runs/specimens, campaigns/apparatus and duplicate publications as appropriate, fit preprocessing on training groups only and reserve independent groups for the held-out evaluation. A within-run fit or a collection of video frames cannot qualify as independent prediction evidence.
- [ ] Before offering any run-level prediction, check endpoint, protocol, reference units/location, material, geometry, apparatus, regime and joint support. Require adequate independent groups, meaningful held-out error/bias in physical units against a simple baseline, residual diagnostics, justified uncertainty and an explicit supported domain. Test transfer on held-out investigations if claiming cross-investigation use. Without sufficient evidence, show why prediction is unavailable. An outside-domain request returns `outside_validated_domain` with no validated value; do not promote extrapolation to a validated prediction.
- [ ] Store immutable method/fit cards and artifacts with code/environment, source snapshot, selected interval or cohort, evaluation, diagnostics and rerun parameters. Keep statistical intervals distinct from measured uncertainty. Other endpoints—including sustained burning, extinction, detection and suppression—retain discovery, evidence, comparisons and all scientifically eligible registered W07 calculations.
