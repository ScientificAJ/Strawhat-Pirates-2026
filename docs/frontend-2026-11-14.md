## Personalization and portability

IndexedDB owns research objects and immutable local revisions. The original
primary database is retained and upgraded without deleting existing cases.
Additional local workspaces have separate databases. An already open tab keeps
its original storage destination when another tab switches workspaces.
Optimistic checks reject stale saves, including attempts to recreate an item
removed by another tab. Recoverable failures retain the draft.

Complete backups use format version 2 and retain version-1 case import. Import
previews the contents, validates and prepares every record before an atomic
write, assigns independent local identities and preserves existing work.
Copied cases reopen their structured companion records; frozen research payloads
and hashes retain original content. Copied selections can be resumed deliberately
in Settings. Appearance/research preferences are applied only when selected.

Backups exclude credentials and active server-job records. Remote IDs in saved
provenance are references, not transferable access. Temporary uploads, execution
sessions and voice/job results can expire; saving a result does not automatically
save all remote files. The Jobs/file controls explicitly retain selected output
bytes locally. The browser backup import profile is 128 MiB; individual retained
output files use the existing 16 MiB artifact profile. Larger research data remains
available through the applicable dataset/download/acquisition paths.

Research reports default to excluding private notes and artifact data. The frozen
revision, source references, qualifications and inclusion choices remain visible.
A report cannot omit critical applicability limits while retaining its conclusion.
Browser backup is a separate, explicit private recovery action. The researcher
can clear the active workspace or all Nova Ember local workspaces, with temporary
server-data deletion separately scoped and explained.

There is no sign-in, cloud synchronization, shared editing or formal human-review
service. Anyone using the same browser profile can see its local research.
Private browsing, storage eviction, site-data deletion or device loss can erase
unexported work. A copied file is an independent workspace, not identity recovery.
