Every checkbox below is **planned**, unless a dated research observation is explicitly identified. Documentation does not establish working code, configured accounts, model access, scientific validation, or a deployed application. No application scaffold, credential, cloud resource, paid inference, sandbox session, staging deployment, or production deployment was created in this planning task. Implement the complete scope through coherent increments; finishing an early increment does not remove later features or change the product into a narrow demonstration.
