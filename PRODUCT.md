# Nova Ember product context

The active [product brief](MASTER_BRIEF.md) owns detailed scope and scientific boundaries. This short context supports design work; it does not create another release checklist.

Nova Ember helps undergraduates, professors, aerospace researchers and engineers investigate combustion and fire safety using NASA research. A curious newcomer should understand the purpose and the next action without learning an application-management system.

The core journey starts with a question or investigation, follows inspectable evidence, compares relevant studies or explores source data, and returns to saved research. The assistant, semantic retrieval, citations, data tools and calculations support this journey. They are not separate setup obligations.

Prevention, detection and suppression organize the research questions. Extraction supports modeling; a descriptive fit is not an independently validated predictor. Earth applications require their own evidence and condition comparisons.

Routine continuity is automatic. Optional notes, saved analyses and backups protect and organize useful work. Source identity, units, uncertainty, access protection and spending limits serve concrete scientific or user needs. Advanced controls are available where their decisions matter.

The product has its own identity. It uses NASA sources and credits them accurately; it does not imply NASA endorsement. Current implementation and dated verification evidence take precedence over historical plans.
